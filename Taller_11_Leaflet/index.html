🗺️ Colombia - División Administrativa

Visualización de departamentos, municipios y ciudades mediante servicios WMS y WFS

📊 Información geográfica

Capas disponibles:

  • Departamentos (33)
  • Municipios (1.122)
  • Ciudades (WFS)

Selecciona una entidad en el mapa para consultar su información geográfica.

🔍 Buscar ciudades

Escribe el nombre de una ciudad para localizarla en el mapa.

🧭 Instrucciones

  • Usa la rueda del ratón para acercar o alejar.
  • Pasa el cursor sobre un departamento para resaltarlo.
  • Haz clic en una entidad para consultar sus atributos.
  • Utiliza el control superior derecho para activar las capas.
  • Busca una ciudad mediante el buscador.

ℹ️ Acerca de

Fuente administrativa: DANE - MGN 2025
Servidor: GeoServer
Base de datos: PostGIS
Estándares: OGC WMS y WFS
Biblioteca: Leaflet.js
